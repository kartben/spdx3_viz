Design notes

  • Why another level? Today's list mixes document chrome (Overview, Graph), inventory types, SPDX profiles, and analysis tools as peers. Profiles are the SPDX mental model users already see as conformance badges on Overview.
  • Lucide: stroke icons align with existing header/palette SVGs; Material filled glyphs in the sidebar currently feel heavier and inconsistent. Lucide can replace view icons only, or eventually the generated node icon set too.
  • Empty profiles stay hidden via the same isViewAvailable rules; a profile group only appears when at least one child is available.
  • Recommendation: Option B. Clear profile identity, collapse keeps long SBOMs scannable, single-view profiles avoid pointless nesting.
Preferred direction: Option B + Lucide for sidebar (and later graph nodes)

# Navigation reorg mockups

Static HTML explorations for promoting SPDX profiles to a clearer top-level nav concept, with Lucide stroke icons.

Open locally:

```bash
python3 -m http.server 8765 --directory mockups
# http://127.0.0.1:8765/nav-reorg.html
```

| File                              | Contents                                      |
| --------------------------------- | --------------------------------------------- |
| `nav-reorg.html`                  | Side-by-side Options A / B / C + design notes |
| `nav-reorg-single.html?o=a\|b\|c` | One sidebar at a time (for screenshots)       |

**Recommendation:** Option B (collapsible profile groups) + Lucide for sidebar icons.
